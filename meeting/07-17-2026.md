## Ideation (30m)

**Hieu — CareMemo: AI Caregiver Visit Companion**
- Voice-first assistant for family caregivers supporting loved ones with dementia, cancer, autism, or other long-term conditions
- Converts natural caregiver updates into confirmed recent observations, major milestones, saved questions, and a visual care timeline
- Generates a concise PDF summary for the next medical appointment without providing diagnosis or medication guidance
- Selling point: caregivers speak naturally while the visit summary builds itself over time through persistent memory
- [More Detail](../ideation/care-memo.md)

**Tri — Gloving Coach Agent (Akky)**
- Computer vision agent that recognizes gloving skill/patterns from video
- Rates performance and tracks skill progress over time
- Recommends new skills/drills to practice next
- Selling point: Novelty, Cost Saving

**Huy — The Front Desk That Never Sleeps**
- 24/7 AI front desk for small businesses (books appointments, answers FAQs, escalates urgent issues)
- Persistent cross-channel memory (chat, SMS, phone) via CockroachDB — remembers customers across sessions
- Selling point: relatable use case, easy demo, fixes missed after-hours bookings
- [More Detail](../ideation/the-front-desk-that-never-sleep.md)

**Ha - TinyQuest AI — Personalized Learning Pet** (demo: https://guide-quake-46421270.figma.site/) 
- AI pet for children: personalized learning quests, healthy habits, and fun rewards
- Remembers interests, learning styles, skill progress, past mistakes, and effective hints
- Selling point: playful child-friendly UI, parent-controlled memory, and clear demonstration of CockroachDB-powered agentic memory

**Ha - CodeRecall AI — Token-Saving Memory for Developer Teams**
- Shared AI memory for development teams: stores previously solved questions, code fixes, architecture decisions, and validated answers
- Before calling an LLM, the agent retrieves similar approved solutions from memory and shows them to the developer first
- If the result is rejected, outdated, or has low confidence, the agent performs a new AI search, then saves the improved solution back to memory
- Selling point: reduces repetitive AI calls and token costs while preserving team knowledge and producing faster, more consistent answers
